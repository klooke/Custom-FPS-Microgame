Build WebGL disponível no Unity Play:

**[▶️ Jogar no navegador](https://play.unity.com/mg/fps/webgl-builds-358361)**

## 📌 Sobre o projeto

Este repositório documenta a customização de um microgame FPS da Unity como atividade de aprendizado. O foco foi praticar o fluxo de desenvolvimento na engine, explorar os sistemas existentes e aplicar modificações no template.

## ✅ Status

Projeto de estudo concluído, com build jogável disponível.
